# 💖 SnapStory AI 📸✨

Welcome to **SnapStory AI** — your magical *Snapchat Movie Storyboard Studio*! 🎬✨

Creating captivating, suspenseful 10-second vertical cinema has never been so easy and adorable! 🍿 Whether you're a budding showrunner or a seasoned director, SnapStory AI is your perfect companion for designing micro-series with flawless AI character consistency, stunning lighting, and seamless cloud collaboration. ☁️🎀

---

## 🌸 Features ✨

- **⏱️ 10-Second Magic Beats:** Instantly parse your script into bite-sized, 10-second high-tension increments perfectly optimized for Snapchat!
- **👯‍♀️ Character Consistency:** Generate a "Character Bible" to keep your cast looking exactly the same across every single scene. No more disappearing signature jackets! 🧥
- **🎨 Visual Vibes:** Choose from gorgeous visual styles like "Cinematic Dark Thriller" or create your own moodboard magic! 🔮
- **📸 Storyboard Studio:** Generate stunning 9:16 vertical storyboard frames and tweak lighting, shadows, and composition until it's absolutely *perfect*. 💖
- **☁️ Cloud Collaboration:** Sync your projects instantly and co-create with your besties in real-time! 👯‍♂️

## 🧸 Getting Started 🚀

Ready to direct your first masterpiece? Let's get things set up! 🎬

### 1️⃣ Clone & Install
```bash
git clone https://github.com/your-username/snapstory-ai.git
cd snapstory-ai
bun install
```

### 2️⃣ Environment Variables
Create a `.env` file in the root directory and add your Google Gemini API key:
```env
GEMINI_API_KEY=your_super_secret_api_key_here
```

### 3️⃣ Run the Magic! ✨
Start the development server:
```bash
bun run dev
```
Open your browser and navigate to `http://localhost:3000` to start creating! 🎉
